# UsefulStuff

A curated personal collection of things worth remembering — repos, websites, tools and
resources — all kept as plain Markdown so they stay diffable, searchable and portable.

Nothing here is copied into the repo. Every entry is a **link plus a short note on why it
matters**, so this stays useful even when the underlying project moves or changes.

## Conventions

- One line per entry: `[name](link)` — a short note on what it is and when to reach for it.
- Group by category headings (`##`). Keep categories flat and obvious.
- Prefer canonical upstream links. If a fork matters, note the upstream it came from.
- Add a `Last checked` date when you verify a link still works.
- Dead or abandoned entries: strike through (`~~link~~`) and note why, rather than deleting
  silently — the history is the value.
