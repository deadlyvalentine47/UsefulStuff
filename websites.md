| Site | What it's for |
|---|---|
| [MDN Web Docs](https://developer.mozilla.org) | Canonical web platform reference (HTML/CSS/JS/APIs). |
| [Can I use](https://caniuse.com) | Browser support tables for web features. |

| [Explainshell](https://explainshell.com) | Break down a shell command argument by argument. |
