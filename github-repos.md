# Useful GitHub Repos

Projects worth knowing about. Each entry: what it is, and when it's the right tool.

## AI / LLM tooling

- [Retrieval-based-Voice-Conversion-WebUI](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI) — VITS-based voice-conversion / voice-changer framework. Good for TTS + voice cloning experiments.
- [bolt.diy](https://github.com/stackblitz-labs/bolt.diy) — prompt, run, edit and deploy full-stack web apps with any LLM. Local, provider-agnostic alternative to hosted AI app builders.
- [openwork](https://github.com/different-ai/openwork) — open-source alternative to Claude Cowork, built for teams, powered by opencode.
- [open-claude-cowork](https://github.com/composio-community/open-claude-cowork) — open-source version of Claude Cowork with 500+ SaaS integrations.
- [lovable-clone](https://github.com/kehanzhang/lovable-clone) — small clone of Lovable; useful reference for building an AI app-generation UI.

## Automation / workflow

- [n8n](https://github.com/n8n-io/n8n) — fair-code workflow automation with native AI features; visual builder, self-hostable, 400+ integrations. The go-to for self-hosted Zapier-style glue.

## Career / interview prep

- [Resume-Matcher](https://github.com/srbhr/Resume-Matcher) — score and tune a resume against a job description with keyword suggestions.
- [leetcode_company_wise_questions](https://github.com/The-Cool-Coders/leetcode_company_wise_questions) — company-wise list of LeetCode premium questions.

## Browser automation / testing

- [Playwright](https://github.com/microsoft/playwright) — cross-browser E2E automation. Pairs with the Playwright projects in this account.
